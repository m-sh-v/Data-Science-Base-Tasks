# Data-Science-Base-Tasks

Сборник ноутбуков с решением задач Data Science.


## Task_1

Данные: Iris (sklearn.datasets)

- корреляционный анализ,
- визуализация признаков и классов,
- сравнение LDA/QDA/логистической регрессии/SVM,
- анализ двух наиболее пересекающихся классов
- ручная реализация квадратичного дискриминантного анализа с проверкой через sklearn.


## Task_2

Данные: mushrooms

- построение решающей функции по каждой переменной на основе частот,
- поиск наиболее информативной переменной,
- построение наивного байесовского классификатора (BernoulliNB),
- ручная реализация наивного байесовского классификатора.


## Task_3

Данные: Obesity_Dataset (kaggle)

- построение и визуализация дерева решений,
- анализ зависимости качества решения от числа листьев,
- тест разных критериев ветвления,
- применение модели градиентного бустинга (GradientBoostingClassifier),
- оценка значимости признаков,
- применение случайного леса.
